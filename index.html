Modul Materi & Konsep

Berfikir Komputasional (CT) membantu kita menstrukturkan penyelesaian masalah. Dalam praktiknya, kita sering menggunakan Algoritma Standar untuk memproses data yang berjumlah besar (Pemrosesan Data) agar lebih efisien.

Pencarian adalah proses menemukan letak suatu data dalam sekumpulan data.

  • Linear Search (Pencarian Sekuensial): Memeriksa setiap elemen data satu per satu dari awal hingga akhir. Cocok untuk data yang belum terurut.
  • Binary Search (Pencarian Biner): Mencari pada data yang sudah terurut dengan cara membagi ruang pencarian menjadi dua secara terus menerus. Sangat cepat untuk data besar!

Pengurutan adalah proses mengatur sekumpulan data menurut aturan tertentu (Menaik/Ascending atau Menurun/Descending).

  • Bubble Sort: Menukar posisi dua data yang berdekatan berulang kali jika urutannya salah, hingga posisi data terbesar "menggelembung" ke ujung.
  • Insertion Sort: Mengambil elemen satu per satu dan "menyisipkannya" ke posisi yang tepat pada bagian data yang sudah terurut sebelumnya.

Siklus dasar pemrosesan data oleh komputer:

INPUT
PROCESS
OUTPUT

Data mentah dikumpulkan (Input), diproses menggunakan algoritma (Process), lalu disajikan menjadi informasi yang bermakna (Output).

Glosarium Interaktif

Ascending
Pengurutan dari nilai kecil ke nilai besar (Menaik).
Descending
Pengurutan dari nilai besar ke nilai kecil (Menurun).
Array
Struktur data untuk menyimpan sekumpulan elemen sejenis.
Efisiensi
Kecepatan algoritma menyelesaikan tugas dengan hemat sumber daya.
